1//! Core library for pore — a full-text search engine built on Tantivy.
2//!
3//! This crate provides the foundational types and abstractions for building
4//! and querying text indexes. It supports two index types:
5//!
6//! - [`FileIndex`] — indexes files in a directory tree, with automatic
7//!   file-walking (respecting .gitignore), content indexing, and line-level
8//!   search result highlighting.
9//! - [`GenericIndex`] — a generic key-value document index where each
10//!   document is a map of named text fields.
11//!
12//! # Re-exports
13//!
14//! The following are re-exported for convenience:
15//! - [`FieldMap`] — trait for extracting field values from data sources
16//! - [`FileIndex`], [`FileIndexOptions`], [`FileSearchOptions`], [`FileSearchResult`]
17//! - [`GenericIndex`], [`IndexOptions`], [`SearchOptions`], [`SearchResult`]
18//! - [`Line`] — a single matching line in search results
19//!
20//! The [`language`] module is also public but not re-exported.
21
