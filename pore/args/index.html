CLI argument parsing for the pore binary.

This module defines the GlobalConfig struct that holds the fully-resolved configuration after merging CLI flags, and the parse_args function that builds it using clap.

§Argument groups

Arguments are split into two conceptual groups:

  • Index options — control which files are indexed and how (hidden files, symlinks, languages, globs, threading). These conflict with --index because a named index carries its own settings from the config file.
  • Search options — control query behavior (limit, threshold, output format, colors).

Four mutually exclusive commands are available via flag groups: --files, --indexes, --delete, or a plain search (default).
