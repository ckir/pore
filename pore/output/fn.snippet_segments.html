fn snippet_segments(snippet: &str) -> Vec<(bool, String)>
Expand description

Splits a Tantivy snippet into (highlighted, text) segments.

[tantivy::snippet::Snippet::to_html] wraps matches in <b> tags and HTML-escapes the surrounding fragment. Terminals want neither, so this decodes the entities and reports which spans were highlighted, leaving the colouring itself to termcolor.
