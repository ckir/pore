Base-directory resolution for the config file and the index cache.

pore follows the XDG layout, but HOME — which the XDG fallback depends on — is not a standard Windows environment variable. Windows sets USERPROFILE; HOME exists only if something else put it there, such as Git Bash or WSL. Depending on HOME alone made every command that touches config or cache fail on a stock Windows box with a bare “environment variable not found”.
